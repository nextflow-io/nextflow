# Executors

In Nextflow, the *executor* is the component that executes tasks submitted by the pipeline.

The executor provides an abstraction between the pipeline definition (*what it computes*) and the underlying execution system (*how it runs*). This way, you can write a pipeline once and run it anywhere -- on your local machine, an HPC cluster, or in the cloud -- simply by using a different configuration profile.

Use [`process.executor`][process-executor] to set the executor, e.g. `process.executor = 'slurm'`. The `local` executor is used by default.
