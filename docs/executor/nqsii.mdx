# NQSII

The `nqsii` executor runs pipeline tasks using the [NQSII](https://www.rz.uni-kiel.de/en/our-portfolio/hiperf/nec-linux-cluster) resource manager. It submits each task as an NQSII job using the `qsub` command.

To enable the NQSII executor, set `process.executor = 'nqsii'` in the `nextflow.config` file. The pipeline must be launched from a node where `qsub` is available, typically the cluster login node.

Resource requests and other job characteristics can be controlled via the following process directives:

- [clusterOptions][process-clusteroptions]
- [cpus][process-cpus]
- [memory][process-memory]
- [queue][process-queue]
- [time][process-time]
