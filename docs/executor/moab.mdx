# Moab

:::warning{title="Experimental: may change in a future release"}
:::

The `moab` executor runs pipeline tasks using the [Moab](https://en.wikipedia.org/wiki/Moab_Cluster_Suite) resource manager by [Adaptive Computing](http://www.adaptivecomputing.com/). It submits each task as a Moab job using the `msub` command.

To enable the `Moab` executor, set `process.executor = 'moab'` in the `nextflow.config` file. The pipeline must be launched from a node where `msub` is available, typically the cluster login node.

Resource requests and other job characteristics can be controlled via the following process directives:

- [clusterOptions][process-clusteroptions]
- [cpus][process-cpus]
- [memory][process-memory]
- [queue][process-queue]
- [time][process-time]
