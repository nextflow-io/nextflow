Many scientific and data-intensive analyses are a chain of command-line tools that pass data to each other as files, rather than through databases or APIs. These pipelines run over thousands of inputs, each step can take hours, and each tool needs specific software versions. Running that reliably means moving files to where the work runs, splitting the work into parallel jobs, submitting them to a cluster or cloud, retrying failures, and keeping track of what has already finished. Nextflow handles this for you. You write each step in any language, and Nextflow stages each task's input files into its own working directory, whether they are stored locally or in cloud object storage. It runs every file through the pipeline in parallel, can give each task its own container, and runs the same pipeline on a laptop, an HPC cluster, or the cloud with only a configuration change. There is no server to deploy, and if a run fails, `-resume` picks up where it stopped.

Nextflow is a workflow system for creating scalable, portable, and reproducible workflows. Its dataflow programming model lets you describe how data moves between steps, and Nextflow works out what can run in parallel. As well as containers, it supports package managers such as Conda and Spack for managing software.

## Get started

To get started with Nextflow:

1. See the Nextflow [overview][overview-page] to learn key concepts
2. Download and [install][install-page] Nextflow
3. Set up an [environment][devenv-page] with the [Nextflow VS Code extension][devenv-nextflow]
4. Run [your first script][your-first-script]

To continue learning about Nextflow, visit the [Nextflow community training portal](https://training.nextflow.io/latest/) and find a training course that is right for you. Seqera, the company that develops Nextflow, also runs a variety of training events. See [Seqera Events](https://seqera.io/events/) for more information.

## Community

You can post questions in the [Nextflow community forum](https://community.seqera.io) or the [Nextflow Slack](https://www.nextflow.io/slack-invite.html). Bugs and feature requests should be reported as [GitHub issues](https://github.com/nextflow-io/nextflow/issues/new/choose).

The Nextflow community is highly active with regular community meetings, events, a podcast, and more. You can view this material on the [Nextflow](https://www.youtube.com/@Nextflow) YouTube channel.

The [nf-core](https://nf-co.re/) project is a community effort aggregating high-quality Nextflow workflows that can be used by everyone.
