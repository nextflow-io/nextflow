# Channel\<E\>

A channel (also known as a *dataflow channel* or *queue channel*) is an asynchronous sequence of values of type `E`. It is used to facilitate dataflow logic in a workflow.

See [Dataflow][dataflow-page] for an overview of dataflow types. See [Operators][operator-typed-page] for the set of operators that are recommended for use with static typing.
