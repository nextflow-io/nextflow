# `machineType`

The `machineType` directive specifies a predefined [machine type](https://cloud.google.com/compute/docs/machine-types) when using the [Google Batch][google-batch-executor] executor, or when using auto-pools with the [Azure Batch][azurebatch-executor] executor.

For example:

```nextflow
process hello {
    machineType 'n1-highmem-8'

    script:
    """
    your_command --here
    """
}
```

See also: [cpus](./cpus), [memory](./memory)
