# `debug`

The `debug` directive prints the standard output of each task to the pipeline standard output.

For example:

```nextflow
process hello {
    debug true

    script:
    """
    echo Hello
    """
}
```

Prints:

```
Hello
```

If you remove the `debug` directive or set it to `false`, `Hello` is not printed.
