# `memory`

The `memory` directive defines how much memory is required by each task execution.

## Usage

For example:

```nextflow
process hello {
    memory 2.GB

    script:
    """
    your_command --here
    """
}
```

Use the following suffixes to specify memory values:

- `B`: Bytes
- `KB`: Kilobytes
- `MB`: Megabytes
- `GB`: Gigabytes
- `TB`: Terabytes

See [MemoryUnit][stdlib-types-memoryunit] for more information.
