# `nextflow secrets`

Manage pipeline secrets.

## Usage

```console
$ nextflow secrets <subcommand> [options]
```

## Description

The `secrets` command manages pipeline secrets, such as API keys and access tokens, without storing them in the pipeline code or configuration. See [Secrets][secrets-page] for more information.

## Options

##### `-h, -help`

Print the command usage.

## Subcommands

##### `list`

List the secrets available in the current store.

##### `get <secret>`

Retrieve a secret value.

##### `set <secret> <value>`

Create or update a secret.

##### `delete <secret>`

Delete a secret.

## Examples

Set a secret:

```console
$ nextflow secrets set FOO "Hello world"
```

List secrets:

```console
$ nextflow secrets list
```

Get a secret:

```console
$ nextflow secrets get FOO
```

Delete a secret:

```console
$ nextflow secrets delete FOO
```
