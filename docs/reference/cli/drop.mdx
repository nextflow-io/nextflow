# `nextflow drop`

<DeprecatedInVersion version="27.04">
The `drop` command has been removed. Delete the project directory from the asset cache instead.
</DeprecatedInVersion>

The `drop` command deleted a project that was downloaded into the asset cache.

## Migrating from `drop`

Projects are downloaded into the asset cache, which is `$NXF_ASSETS` (default: `$HOME/.nextflow/assets`). Delete the project directory to remove it:

```bash
# before
nextflow drop nextflow-io/hello

# after
rm -rf ~/.nextflow/assets/.repos/nextflow-io/hello
```

Projects downloaded by older versions of Nextflow are stored in `$NXF_ASSETS/<org>/<repo>` (e.g., `~/.nextflow/assets/nextflow-io/hello`). Use `nextflow info <project>` to print the local path of a project.

To remove a pipeline installed with `nextflow pipeline install`, use `nextflow pipeline remove` instead.
