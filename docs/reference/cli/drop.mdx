# `nextflow drop`

<DeprecatedInVersion version="27.04">
Use [`nextflow project remove`][cli-project-remove] instead.
</DeprecatedInVersion>

Delete the local copy of a project.

The `drop` command is an alias of [`nextflow project remove`][cli-project-remove] and accepts the same options.
