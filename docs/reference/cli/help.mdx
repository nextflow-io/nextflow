# `nextflow help`

Print the top-level help or specific help for a command.

## Usage

```console
$ nextflow help [options] [command]
```

## Description

The `help` command prints an overview of the CLI and lists the top-level *options* and *commands*. It is equivalent to running `nextflow` with no arguments.

## Options

##### `-h, -help`

Print the command usage.

## Examples

Print the help for the `info` command:

```console
$ nextflow help info

Print project and system runtime information
Usage: info [options] project name
  Options:
    -u, -check-updates
       Check for remote updates
       Default: false
    -d
       Show detailed information
       Default: false
    -h, -help
       Print the command usage
       Default: false
    -o
       Output format, either: text (default), json, yaml
```
