# `nextflow help`

Print the top-level help or specific help for a command.

## Usage

```console
$ nextflow help [options] [command]
```

## Description

The `help` command prints an overview of the CLI and lists the top-level *options* and *commands*. It is equivalent to running `nextflow` with no arguments.

## Options

##### `-h, -help`

Print the command usage.

## Examples

Print the help for the `self-update` command:

```console
$ nextflow help self-update

Update nextflow runtime to the latest available version
Usage: self-update [options]
   Options:
     -clean
          Remove the files of all other Nextflow versions after updating
          Default: false
     -h, -help
          Print the command usage
          Default: false
```
