# `nextflow clone`

<DeprecatedInVersion version="27.04">
The `clone` command has been removed. Use `git clone` instead.
</DeprecatedInVersion>

The `clone` command downloaded a pipeline from a Git-hosting platform into a local directory.

## Migrating to `git clone`

Clone the pipeline repository with Git. Use `--branch` to check out a branch or tag, and `--depth` for a shallow clone:

```bash
# before
nextflow clone nextflow-io/hello -r v1.1

# after
git clone --branch v1.1 https://github.com/nextflow-io/hello
```

To run a registry pipeline, or include it in another pipeline, use `nextflow pipeline install` instead.
