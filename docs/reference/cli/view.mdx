# `nextflow view`

<DeprecatedInVersion version="27.04">
The `view` command has been removed. Use `nextflow pipeline view` instead.
</DeprecatedInVersion>

The `view` command printed the main script, or listed the files, of a project in the asset cache.

## Migrating from `view`

- Use [`nextflow pipeline view`](./pipeline#pipeline-view) to view the details of a registry pipeline.
- Use `nextflow info <project>` to print the local path of a downloaded project, then browse its files directly.
