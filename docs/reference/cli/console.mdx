# `nextflow console`

Launch the Nextflow interactive console.

## Usage

```console
$ nextflow console
```

## Description

The `console` command opens a graphical user interface (GUI) with an interactive read-eval-print loop (REPL) for quick experimentation.

## Options

None available.

## Examples

Launch the `console` GUI:

```console
$ nextflow console
```
