# `console`

Launch the Nextflow interactive console.

## Usage

```console
$ nextflow console
```

## Description

The `console` command provides a Graphical User Interface (GUI) and an interactive REPL (Read-Eval-Print-Loop) for quick experimentation.

## Options

None available.

## Examples

Launch the `console` GUI:

```console
$ nextflow console
```
