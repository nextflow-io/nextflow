# Namespaces

A namespace groups a set of related constants and functions that Nextflow makes available to every script. The global namespace is available without a prefix, while the remaining namespaces are accessed by name, such as `workflow.projectDir`.

## Available namespaces

| Page | Description |
| ---- | ----------- |
| [Global namespace][stdlib-namespaces-global] | The globally available constants and functions. |
| [`channel`][stdlib-namespaces-channel] | The built-in channel factories. |
| [`log`][stdlib-namespaces-log] | Functions for logging messages to the console. |
| [`nextflow`][stdlib-namespaces-nextflow] | Information about the current Nextflow runtime. |
| [`workflow`][stdlib-namespaces-workflow] | Information about the current workflow run. |
