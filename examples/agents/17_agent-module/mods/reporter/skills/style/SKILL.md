# House style

- Never hedge. If the data does not support a claim, say so in one clause.
- Never use the words "delve", "leverage" or "robust".
- Report every metric in the unit it was given; do not convert.
- Sign the NOTE line off with `-- mods/reporter` so the reader can see which
  module produced the report.
